# ⚡️ Zeus Scanner

**Zeus Scanner** یک اسکنر IP برای Cloudflare است که با هسته‌ی واقعی **Xray** کار می‌کند.

این ابزار IPهای لبه‌ی Cloudflare را با **TLS/SNI** بررسی می‌کند، بهترین IPها را با هسته‌ی واقعی Xray و کانفیگ خودت تست می‌کند و در صورت فعال‌بودن Speedtest، سرعت اتصال را از داخل همان Tunnel اندازه‌گیری می‌کند.

---

## 🚀 نصب روی Termux

برای نصب کافی است یک دستور اجرا کنید:

```bash
curl -fsSL https://raw.githubusercontent.com/frankfuvgfugkfc/scanner/main/install.sh | bash
```

بعد از اتمام نصب:

```bash
zeus
```

برنامه به‌صورت خودکار مرورگر را روی آدرس زیر باز می‌کند:

```text
http://127.0.0.1:8000/
```

نصب Python، شناسایی معماری پردازنده، دانلود نسخه‌ی مناسب Xray و تنظیم فایل‌ها به‌صورت خودکار انجام می‌شود.

> این روش روی Linux Desktop نیز قابل استفاده است.

---

## 🧠 نحوه‌ی کار

### 1. 🔎 کشف IP

ابزار روی IPهای موردنظر و پورت‌های انتخابی، اتصال TLS برقرار می‌کند و **SNI پنل شما** را ارسال می‌کند.

### 2. ✅ تأیید HTTP

پس از برقراری TLS، پاسخ HTTP بررسی می‌شود.

پاسخ‌هایی که دارای یکی از موارد زیر باشند به‌عنوان Cloudflare شناسایی می‌شوند:

```text
cf-ray
Server: cloudflare
```

کدهای زیر نشان‌دهنده‌ی IP زنده‌ای هستند که درخواست را رد کرده است:

```text
403
409
429
```

این IPها در نتایج تمیز قرار نمی‌گیرند.

### 3. 🎯 غربال‌گری قیفی

برای لیست‌های بزرگ، تا حدود **1000 IP**، ابتدا تمام IPها به‌صورت سریع بررسی می‌شوند.

سپس فقط IPهای برتر چند بار و با دقت بیشتر تست می‌شوند.

این روش باعث می‌شود بین **سرعت اسکن و دقت نتایج** تعادل برقرار شود.

### 4. 📊 اندازه‌گیری دقیق

تست‌ها چندین بار تکرار می‌شوند و معیارهای مختلفی محاسبه می‌شوند:

- Median
- Jitter
- Packet Loss
- TCP Connect Time
- TLS Handshake Time

### 5. 🚀 تست واقعی Xray

برای IPهای برتر، یک Tunnel واقعی با استفاده از **کانفیگ خود شما** ایجاد می‌شود.

سپس درخواست `generate_204` از داخل Tunnel ارسال می‌شود.

اگر پاسخ معتبر دریافت شود، مشخص می‌شود که IP موردنظر واقعاً می‌تواند کانفیگ شما را عبور دهد.

### 6. ⚡ Speedtest واقعی

با فعال‌کردن گزینه‌ی **Speedtest**، سرعت اتصال از داخل همان Tunnel و با:

```text
speed.cloudflare.com
```

اندازه‌گیری می‌شود.

بنابراین تست سرعت روی یک Socket خالی انجام نمی‌شود و نتیجه مربوط به مسیر واقعی Tunnel است.

## 🔑 نکته‌ی مهم درباره‌ی Xray

در کانفیگ ساخته‌شده برای تست، فقط مقدار:

```text
address
```

با IP کاندید جایگزین می‌شود.

در مقابل، مقادیر:

```text
serverName
Host
```

بدون تغییر باقی می‌مانند.

به این ترتیب تنظیمات اصلی کانفیگ ثابت هستند و فقط Edge IP مورد آزمایش تغییر می‌کند.

## ⚙️ متغیرهای محیطی

| متغیر | مقدار پیش‌فرض | توضیح |
|---|---|---|
| `ZEUS_PORT` | `8000` | پورتی که رابط کاربری روی آن اجرا می‌شود |
| `XRAY_BIN` | `./bin/xray` | مسیر فایل اجرایی Xray |
| `ZEUS_DIR` | `~/zeus-scanner` | مسیر محل نصب |
| `ZEUS_XRAY_TAG` | `latest` | نسخه‌ی Xray برای دانلود |

مثلاً برای تغییر پورت:

```bash
ZEUS_PORT=9000 zeus
```

یا برای مشخص‌کردن مسیر Xray:

```bash
XRAY_BIN=/path/to/xray python3 server.py
```

## 🪟 Windows

فایل:

```text
server.ps1
```

نسخه‌ی PowerShell اسکن TLS/SNI و لغو واقعی اسکن را پشتیبانی می‌کند.

با این حال، قابلیت‌های زیر در نسخه‌ی Python کامل هستند:

- اجرای Xray
- Speedtest داخل Tunnel
- حالت اسکن دقیق

رابط کاربری وضعیت قابلیت‌ها را از:

```text
/api/ping
```

تشخیص می‌دهد و گزینه‌هایی را که در Windows پشتیبانی نمی‌شوند، غیرفعال می‌کند.

## 🛠 اجرای دستی

اگر نمی‌خواهید از Installer استفاده کنید:

```bash
git clone https://github.com/frankfuvgfugkfc/scanner
cd scanner
python3 server.py
```

### Xray

برای فعال‌شدن تست Xray، فایل اجرایی هسته را در مسیر زیر قرار دهید:

```text
./bin/xray
```

یا مسیر آن را با متغیر محیطی `XRAY_BIN` مشخص کنید:

```bash
export XRAY_BIN=/path/to/xray
```

بدون Xray نیز اسکن IP انجام می‌شود، اما ستون **Xray** در نتایج خالی خواهد بود.
