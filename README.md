# Zeus Scanner

اسکنر آی‌پی تمیز کلادفلر با هسته‌ی واقعی Xray.
آی‌پی‌های لبه‌ی Cloudflare را با TLS/SNI تست می‌کند، بهترین‌ها را با **هسته‌ی واقعی Xray روی کانفیگ خودت** اعتبارسنجی می‌کند و برایشان **speedtest واقعی از داخل تانل** می‌گیرد.

## نصب روی ترموکس (یک خط)

```bash
curl -fsSL https://raw.githubusercontent.com/frankfuvgfugkfc/scanner/main/install.sh | bash
```

بعد از نصب:

```bash
zeus
```

مرورگر روی `http://127.0.0.1:8000/` باز می‌شود. همین. نصب پایتون، دانلود هسته‌ی Xray مناسب CPU گوشی، دانلود فایل‌های اسکنر و ساخت دستور `zeus` همه خودکار انجام می‌شود.

روی لینوکس دسکتاپ هم همان دستور کار می‌کند.

## چطور کار می‌کند

1. **کشف** — به هر آی‌پی روی پورت‌های انتخابی TLS می‌زند و SNI پنل خودت را می‌فرستد.
2. **تأیید HTTP** — پاسخ باید هدر `cf-ray` یا `Server: cloudflare` داشته باشد. وضعیت ۴۰۳/۴۰۹/۴۲۹ یعنی آی‌پی در دسترس است ولی ما را رد می‌کند، پس تمیز نیست.
3. **اندازه‌گیری دقیق** — چند بار تکرار، میانه و جیتر و پکت‌لاست جدا، زمان TCP و TLS جدا.
4. **تست واقعی Xray** — برای آی‌پی‌های برتر یک تانل واقعی با کانفیگ خودت بالا می‌آید و از داخلش `generate_204` گرفته می‌شود. اگر ۲۰۴ برگشت، آن آی‌پی واقعاً کانفیگ تو را حمل می‌کند.
5. **speedtest واقعی** — وقتی «تست سرعت» روشن باشد، سرعت از داخل همان تانل با `speed.cloudflare.com` سنجیده می‌شود، نه روی سوکت خالی.

نکته‌ی کلیدی مرحله‌ی ۴: در کانفیگ ساخته‌شده فقط `address` با آی‌پی کاندید عوض می‌شود؛ `serverName` و `Host` دست‌نخورده می‌مانند. یعنی هر چیزی که سرور اعتبارسنجی می‌کند ثابت است و تنها لبه‌ای که از آن رد می‌شویم تغییر می‌کند.

## فایل‌ها

| فایل | کار |
|---|---|
| `install.sh` | نصب‌کننده‌ی یک‌خطی ترموکس/لینوکس |
| `index.html` | رابط کاربری |
| `server.py` | هسته‌ی اسکن و API |
| `xray.py` | مدیریت هسته‌ی Xray، پارس کانفیگ، تانل، speedtest |
| `server.ps1` | هسته‌ی ویندوز (PowerShell) |

## متغیرهای محیطی

| متغیر | پیش‌فرض | کار |
|---|---|---|
| `ZEUS_PORT` | `8000` | پورت رابط کاربری |
| `XRAY_BIN` | `./bin/xray` | مسیر هسته‌ی Xray |
| `ZEUS_DIR` | `~/zeus-scanner` | محل نصب |
| `ZEUS_XRAY_TAG` | `latest` | نسخه‌ی Xray برای دانلود |

## ویندوز

```powershell
.\server.ps1
```

## اجرای دستی (بدون نصب‌کننده)

```bash
git clone https://github.com/frankfuvgfugkfc/scanner
cd scanner
python3 server.py
```

برای فعال شدن تست Xray، هسته را در `./bin/xray` بگذار یا `XRAY_BIN` را ست کن. بدون آن اسکن کار می‌کند ولی ستون Xray خالی می‌ماند.
